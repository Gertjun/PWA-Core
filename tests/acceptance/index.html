2. Lokale testkluis

Maak op elk apparaat een eigen testkluis. De datasleutel wordt uitsluitend met je testwachtwoord versleuteld opgeslagen; het wachtwoord zelf wordt niet bewaard.

Gebruik hetzelfde testwachtwoord op een apparaat waarop je een bestaande testpasskey wilt koppelen. De testkluis zelf is lokaal en wordt niet gesynchroniseerd.

3. Passkey / PRF

Bij koppelen op iPad selecteer je de testpasskey die via iCloud-sleutelhanger beschikbaar is. Op Windows kun je afzonderlijk testen met Windows Hello. Annuleer een prompt ook eenmaal om de foutafhandeling te controleren.

Deze knoppen verwijderen geen passkey uit iCloud-sleutelhanger of Windows Hello. Verwijder de testpasskey daar afzonderlijk als de test klaar is.
